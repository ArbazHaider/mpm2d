📋 Project Brief — City of Toronto Engineering Division

The City of Toronto requires a structural analysis for a new secondary pedestrian pathway mirroring the iconic Humber Bay Arch Bridge near Lake Ontario. Preliminary surveying software has generated the following structural model:

h(x) = −0.01x² + 1.2x + 4

where h(x) is the arch height in metres above water level, and x is the horizontal distance in metres from the western observation deck.

x = −b ± √(b²−4ac) / 2a

👥 Collaborative · Partner Discussion

Structural Theory — Interpreting the Model

▾

Before touching any calculator, discuss the following with your engineering partner. Use the simulator to visualize each concept as you discuss it.

"What does the constant value c = 4 represent in the physical environment of this bridge?"
The constant c is the y-intercept — the height of the arch at x = 0, i.e., directly at the western observation deck. Since h(0) = 4, the arch begins 4 metres above water level at that point. This represents the elevation of the deck above the Humber River.
"Why must the leading coefficient a be negative for this bridge design?"
A negative a value produces a downward-opening parabola — an arch shape. If a were positive, the parabola would open upward (like a valley or cable), which cannot model an arch bridge that rises above the water and descends to anchoring points.
"Which mathematical features of this parabola represent the concrete foundation points at water level?"
The x-intercepts (roots/zeros) of h(x) are where h(x) = 0 — where the arch height equals zero, meaning the arch meets water level. These are precisely the locations where the steel arch anchors into the riverbanks.

Foundation Coordinates — Applying the Quadratic Formula

▾
1
Set h(x) = 0: 0 = −0.01x² + 1.2x + 4
Identify: a = −0.01, b = 1.2, c = 4
2
Calculate the discriminant: b² − 4ac = (1.2)² − 4(−0.01)(4)
= 1.44 + 0.16 = 1.60
3
Apply the quadratic formula: x = (−1.2 ± √1.60) / (2 × −0.01)
